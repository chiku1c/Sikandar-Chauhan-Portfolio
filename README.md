# Sikandar Chauhan — Portfolio

A modern React + Vite portfolio for Software Engineer / Frontend Developer.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL shown by Vite.

## Build

```bash
npm run build
```

The production files are created in `dist/`.

## Deploy to Vercel

1. Create a GitHub repository and upload this project.
2. Sign in to Vercel with GitHub.
3. Import the repository.
4. Framework preset: Vite.
5. Build command: `npm run build`
6. Output directory: `dist`
7. Deploy.

## Before publishing

Replace the placeholder LinkedIn and GitHub URLs in `src/main.jsx` with the real profile URLs.
Add the final PDF resume as `public/Sikandar-Chauhan-Resume.pdf` if you want a resume-download button.
